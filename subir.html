Conectar con GitHub

Solo se hace una vez en este móvil. La llave se guarda únicamente aquí, en este navegador.

  1. Abre github.com → Fine-grained token.
  2. En Repository access elige Only select repositories y marca solo este repositorio.
  3. En Permissions → Contents elige Read and write. Nada más.
  4. Crea el token, cópialo y pégalo abajo.
